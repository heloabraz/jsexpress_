# Cadastro Simples — Sistema CRUD com Node.js

## Nome do Projeto
**Cadastro Simples** — sistema para gerenciamento de clientes, fornecedores e produtos.

## Integrantes
- Eloá Braz
- Isabella Barbosa

## Objetivo
Finalizar um sistema CRUD desenvolvido em Node.js, garantindo o funcionamento das operações de cadastrar, listar, editar e excluir. O projeto também passou por uma reestilização da interface com apoio de uma ferramenta de Inteligência Artificial.

## Tecnologias Utilizadas
- Node.js
- Express
- EJS
- HTML5 e CSS3
- JavaScript
- Arquivos JSON para armazenamento dos registros
- ChatGPT como apoio para sugestões de design

## Funcionalidades
- **Create (Cadastrar):** adicionar clientes, fornecedores e produtos.
- **Read (Listar):** visualizar os registros cadastrados.
- **Update (Editar):** alterar os dados de um registro existente.
- **Delete (Excluir):** remover um registro, com confirmação antes da exclusão.
- Validação de campos obrigatórios, e-mail e valores numéricos.
- Interface adaptada para telas menores.

## Como executar o projeto
1. Instale o Node.js.
2. Abra o terminal na pasta do projeto.
3. Execute `npm install`.
4. Execute `npm start`.
5. Acesse `http://localhost:3000` no navegador.

## Uso da Inteligência Artificial
Foi utilizado o ChatGPT como apoio para avaliar a apresentação visual do sistema e propor melhorias de usabilidade. As sugestões serviram como orientação; o código foi revisado e ajustado para a estrutura real do projeto.

## Alterações Sugeridas pela IA
- Criar uma página inicial mais organizada, com acesso direto às áreas do sistema.
- Melhorar a hierarquia visual dos títulos, textos e informações.
- Padronizar botões, formulários e tabelas.
- Utilizar cores suaves e melhor espaçamento.
- Exibir uma mensagem quando ainda não houver registros.
- Adaptar o layout para diferentes tamanhos de tela.

## Alterações Implementadas pelo Grupo
- Reorganização da página inicial em cartões para Clientes, Fornecedores e Produtos.
- Aplicação de uma identidade visual discreta, com verde suave, tons neutros e fundo claro.
- Criação de cabeçalho, navegação de retorno e indicação da quantidade de registros.
- Reformulação das tabelas, formulários, botões e mensagens de lista vazia.
- Ajustes de responsividade para telas menores.
- Revisão das rotas de cadastro, edição e exclusão, além de validações dos campos.
- Inclusão dos nomes corretos das integrantes na página inicial e neste README.
